# Unreal Engine Layers

Unreal Engine 5.x High Level Architecture

Interactive diagram of the 9 layers of Unreal Engine, from game to hardware. Available in English and Portuguese (flag switch in the top-right corner; English by default).

- Drag to move; Ctrl + wheel (or pinch) to zoom
- Click a flow to highlight it
- Download as SVG or PNG
- Edit the Mermaid code in the "Code" panel

Direct links: `#en` or `#pt` at the end of the URL open the page in that language.

Hosted with GitHub Pages: just keep `index.html` at the root of the repository.
